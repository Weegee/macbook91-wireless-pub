Structure version: 20261026.01

Layout rules for this repository. The README describes the same directories
for a reader; this file is the rule.

src/macbook91-wireless/   the DKMS module tree, copied to
                    /usr/src/macbook91-wireless-<pkgver>. It TRACKS only what
                    this project wrote: Makefile, dkms.conf, modprobe.d/. The
                    kernel half is generated by packaging/fetch-upstream.sh
                    and gitignored: series/<S>/ per shipped kernel series
                    (kernel/, patches/ as a copy, KERNEL-SERIES, KERNEL-TAG,
                    UPSTREAM.sha256 - its manifest, whose hash is the module
                    ID of that series), KERNEL-SERIES (the list of series,
                    one per line; make install turns it into
                    BUILD_EXCLUSIVE_KERNEL in dkms.conf) and UPSTREAM.lock
                    (the lock lines of their tags). The Makefile builds the
                    series of the target kernel into build/, which dkms.conf
                    names for all five modules.
patches/            the project's changes to kernel code: one set for every
                    kernel series in upstream.lock, applied to each tag with
                    patch -F0 (line offsets, no fuzz); no per-series
                    directory (tests/ check it). `git format-patch
                    --zero-commit` output of the development tree
                    build/dev/<series> (branch macbook91). Never a test-only
                    patch.
packaging/          files.list (the kernel files fetched), overlay/ (the two
                    Kbuild files), upstream.lock (hashes that gate every
                    fetched file and the derived tree), fetch-upstream.sh,
                    mkdist.py (reproducible tarball), promote-release.sh,
                    make-package.sh, arch/ (PKGBUILD, .SRCINFO, install
                    scriptlet).
tools/              macbook91-wireless-verify is packaged to /usr/bin;
                    kernel-series to /usr/lib/macbook91-wireless/, the one
                    reader of KERNEL-SERIES besides the module Makefile
                    (dkms.conf pattern, pacman hook, install scriptlet,
                    verifier); macbook91-wireless-series.hook to
                    /usr/share/libalpm/hooks/71-macbook91-wireless-series.hook.
                    dev-*.sh are development helpers and not packaged.
tests/              hermetic tests: no root, no hardware, no network.
docs/               FINDINGS.md (status-tagged findings), CHANGELOG.md,
                    test-status.json (the gate record),
                    NAMCAP.md (namcap warnings and why they stay).
diag/<date>/        redacted raw diagnostics (see diag/README.md);
                    DIAGNOSIS.md is the first report.
release/<version>/  promoted releases (promote-release.sh), SHA256SUMS over the
                    tracked files. promote-release.sh keeps the two newest;
                    older ones are removed from the tree.
Makefile, VERSION   the package contract shared with the other
                    macbook91 packages: `make dist`, `make install`, `make arch-pkg`.
                    VERSION is the single version (YYYYMMDD.NN); PKGBUILD
                    pkgver and the tag v<VERSION> must equal it.
LICENSE, LICENSES/  LICENSE is the GPL-3.0 text, the license of this
                    project's own files; LICENSES/ holds that text under its
                    SPDX name (GPL-3.0-or-later.txt, identical to LICENSE;
                    not part of the source tarball) and the other license
                    texts the package needs (GPL-2.0-only, GPL-2.0-or-later,
                    ISC for brcmfmac, MIT for hci_aml.c). Own files that build
                    or install the modules (Kbuild files, the module tree's
                    Makefile, dkms.conf, scripts DKMS runs) are
                    GPL-2.0-or-later, as GPLv2 requires them with a built
                    module; kernel files, patches and copies of kernel code
                    keep the kernel file's license. Every own file with
                    comment syntax names its license in an
                    SPDX-License-Identifier line, after the shebang if any;
                    tests/run-tests.sh checks it. README.md, "License", maps
                    the paths.

Never tracked: unredacted local logs and captures, Apple/Broadcom binaries,
build/, dist/. No firmware, no MAC/Bluetooth addresses, SSIDs, IP
addresses, serial numbers or personal e-mail addresses anywhere in Git;
tests/run-tests.sh checks the mechanical part of that.
